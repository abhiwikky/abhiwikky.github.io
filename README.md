Personal portfolio of Abhijith S: incident response, malware analysis, detection engineering and cloud security.

**Live site:** [abhijith.is-a.dev](https://abhijith.is-a.dev)

[![Portfolio](https://img.shields.io/badge/View%20My%20Portfolio-20D6BE?style=for-the-badge&logo=google-chrome&logoColor=white)](https://abhijith.is-a.dev)

## Stack

Vite · React · TypeScript · Tailwind CSS · Framer Motion. Deployed to GitHub Pages via `.github/workflows/pages.yml`.

## Run locally

```bash
npm install
npm run dev      # http://localhost:8080
npm run build
```
